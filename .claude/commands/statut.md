---

Utilise l'agent `pm` pour calculer l'avancement à partir de l'état réel de GitHub (issues, milestones, PR, branches) et de `docs/ROADMAP.md`. N'écris aucun fichier.

Donne-moi, directement dans la conversation, 10 lignes maximum :
- avancement par milestone (chiffres) ;
- ce qui a été fait depuis le dernier point ;
- ce qui bloque ou traîne (PR sans relecture, issues sans activité, branches orphelines) ;
- la prochaine issue à lancer avec `/tache <n>` ;
- ce que j'ai à décider ou à merger.
