# Specs

Une spec par phase ou grosse fonctionnalité, nommée `phase-<n>-<slug>.md`, tenue par l'agent `product` (commande `/spec`).

`docs/ROADMAP.md` donne la vue d'ensemble des phases ; chaque spec en détaille les user stories, critères d'acceptation et règles métier. Les issues GitHub citent la spec dont elles dépendent.
